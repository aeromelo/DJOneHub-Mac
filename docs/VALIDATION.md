# 验证范围

第一版发布前应记录当前构建、安装和测试结果。隐私数据不作为附件上传。

## 已有真实验证（同一测试 Mac 与模块）

- 手动 Wi-Fi / 4G 切换、4G 时关闭 Wi-Fi、模块拔插菜单隐藏与重新出现。
- 4G 下普通网页、YouTube 与实际 Codex 对话可用。
- Clash Verge TUN 保留，4G 出口与本地 DNS 联动。
- 11 个选定 VPN 站点证书验证 TLS 握手；取消勾选后不参加测试。
- 电信短信额度解析和本地累计；联通确实有仅返回官方 App 链接的卡，未伪造余额。
- 显示器熄屏 / 屏保持续至少三分钟后，用户确认解锁仍联网，无需拔插或重新选择。
- 此前增强版通话已由用户确认接通、双方可听到声音。

## 自动化验证

Python 测试覆盖：出口选择、自动开关、VPN 选择、TLS 证书、检测状态、USB 接口变化后的唤醒恢复、三家运营商短信样式、限定流量排除、计数器重置、状态轮询不发短信、SIM 更换、运营商拒绝/仅 App 链接、安装保留数据与失败恢复、构建时复用已校验上游目录。原生 self-test 检查上游通知格式、信号等级、64 位网卡计数采样和 Dock 偏好保存。

## 尚未实测 / 适用限制

- 所有型号 Mac、所有 macOS 版本、Intel、全新无历史安装的物理 Mac。
- 所有运营商省份和卡种；移动使用样本单元测试，未用真实移动 SIM 验证。
- 所有代理软件、节点和站点账号；检测仅衡量连接与 TLS，不承诺业务可用。
- 全部 iPad 直连组合；已有一台 M1 iPad Pro 通过扩展坞联网经验。
- 手动整机睡眠、合盖、极低电量及长时间断电后的每一种 USB 恢复情形。

发行构建与统一 App 的现场结果见 [发行验证记录](RELEASE_VALIDATION.md)。
