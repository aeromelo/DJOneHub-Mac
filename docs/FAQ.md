# 故障排查

### 菜单不见了

菜单按约定只在检测到模块 USB 网卡连接时显示。先打开 DJOneHub.app，确认有线配件已允许、线材支持数据，查看系统网络和 USB 列表。插在固定端口不是要求。数据接口可能随端口变更得到不同 en 编号。

### 手动切换灰色

“自动使用 4G”开启时手动选项禁用。关闭它再手动选 Wi-Fi 或 4G；关闭自动开关不会立即切回 Wi-Fi。

### Wi-Fi 有信号，但正在用 4G

自动模式默认使用模块。手动 4G 也会关闭 Wi-Fi 无线电，减少出口混用。要恢复 Wi-Fi 请关闭自动模式并选择 Wi-Fi。

### 外国网站能打开，检测却失败

本版已经改为 Clash Verge 风格的证书验证 TLS 握手，不按完整网页的 403 判断禁止。检查检测时间、当前出口是否已变化、该站是否被选中，以及现有代理的节点和规则。TLS 正常只能证明连接路径，不检查账号或服务本身。

### 4G 可访问普通网站，YouTube 或 Codex 不通

核实现有 Clash 已运行、TUN 与 DNS 正常，点“重新检测代理出口”后再检测。App 不自带代理，也不能让运营商网络天然访问所有站点。原有 TUN 模式保留；不会替用户更改订阅或节点。

1.0.1 修复了隧道仍复用旧路由的情况：即使 LTE 已注册、网卡有地址，1.0.0 的 TUN 路径仍可能超时。请升级 1.0.1；切换按钮会在物理出口确定后重建 TUN，再等待 DNS 就绪。TUN 最终仍开启，原有节点选择保留。

### App 被改名后，控制后台启动失败

后台启动项指向 `~/Applications/DJOneHub.app`。请使用随包安装器升级并保留这个名称；直接拖动、改名或创建另一份 App 可能让后台仍指向旧位置。可重新运行随包安装器修复，先保留原有数据目录。

### 熄屏后断网

4G 时菜单应显示“允许熄屏，防止自动整机睡眠”。可用 `pmset -g assertions` 查看名为“DJOneHub: keep USB 4G awake while display sleeps”的声明。检查 App 是否仍在运行。合盖、手动睡眠、低电量或 USB 掉电仍可能触发真睡眠。唤醒后等待 USB 枚举和自动恢复，最长约两分钟；仍失败请提供连接方式和脱敏日志。

### 联通短信没有流量

部分地区不接受 CXLLJ，本版默认 CXTCYL，并提供 2082、CXLL、1071、CXLLJ。官方短信入口也可能只返回联通 App 链接，没有数字额度。显示这种状态是运营商的实际回复，不能从链接制造一个套餐余额。可手动改指令查询；不要连续盲目发送或使用开通业务的指令。

### 本地剩余和营业厅不同

本地是短信基线减去本机可观测的 RX + TX，不是实时营业厅余额。其他设备、共享卡成员、App 关闭期间、月结和定向包都会影响对账；点击短信同步可重新建立基线。

### 通话无声

允许麦克风，确认 SIM 有语音业务、模块通话组件与 USB 音频模式就绪。iPhone/iPad 模式可能关闭 USB Audio。请按增强版文档处理硬件要求，不要未经理解反复写 USB 配置。

### 端口 7575 或主窗口离线

后台只在本机 127.0.0.1:7575 提供 API。检查 com.jamie.djonehub 用户服务与 Logs/DJOneHub。请避免另开一份旧增强版后端占同一端口。新安装备份旧服务，正常情况下只应有一个 djonehub-macos 进程。

### 升级后识别到网卡，但请求都超时

切换后旧代理连接或 USB 数据通道可能尚未恢复。本版会重建现有 Mihomo 出口并等待 DNS 就绪；请先重新检测代理出口。仍失败时，先恢复 Wi-Fi，将模块拔下等 10 秒再接回并允许配件，等待取得地址后重新选择 4G 和检测。网卡已显示、LTE 已注册本身不代表数据链路可用；请以实际请求结果为准。
