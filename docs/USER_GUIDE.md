# 使用说明

## 打开与退出

安装后，在当前用户的 Applications 文件夹打开 DJOneHub.app。主窗口是增强版原生界面，提供拨号、最近通话、短信、通讯录及设置。网络菜单在同一进程中启动；不会额外打开浏览器或运行第二个菜单 App。

关闭窗口只隐藏主窗口，通知和网络菜单继续运行；再次打开 App 或点击菜单“打开 DJOneHub”回到主窗口。菜单在模块连接后显示，拔下后隐藏。GPS 开启时，上游的独立 GPS 图标仍可出现。

菜单“退出 DJOneHub”恢复本工具添加的代理/DNS与 Wi-Fi 状态并退出前台 App；后台模块服务仍可运行。上游设置里的“完全退出”停止模块后台服务，重新打开 App 会重新引导服务。连接恢复可能需要数秒。

## Wi-Fi 与 4G

1. 关闭“自动使用 4G”，两项手动网络选择可点击。
2. “使用 4G 上网”：选择当前枚举到的模块网卡，设置服务优先级，关闭 Wi-Fi 无线电。已运行的 Clash 可绑定到该网卡，并使用现有本地代理/DNS。
3. “使用 Wi-Fi 上网”：打开 Wi-Fi，等待地址与路由建立，恢复本工具为 4G 网卡添加的代理和 DNS。
4. 网络切换后自动检测联网；网络变化期间已有应用连接可能需要重连。

**自动开关开启时，默认固定使用 4G。** 模块就绪即切换，Wi-Fi 即使可用也不作为首选；手动选项变灰。关闭开关只解除自动接管，不立即改动当前出口，此时再选择需要的网络。

USB-C 接口不必固定：工具根据当前系统枚举到的网卡选择出口，换口导致 en 编号变化时会重新读取。端口、线材和扩展坞必须支持数据传输，出现 macOS 配件提示请允许。

拔下模块时，恢复由本工具关闭的 Wi-Fi，再隐藏菜单。若 Wi-Fi 本来就没有可连接的网络，恢复无线电不保证立即能上网。

## 信号与电源

信号来自模块 AT 查询，以 dBm 和四格图标显示。阈值为：≥ -85 四格，≥ -95 三格，≥ -105 两格，更弱一格。查询失败显示“暂未读到”，不会生成虚假信号。

4G 作为当前出口且模块连接时，App 创建 macOS 的“防止闲置整机睡眠”电源声明；屏幕仍可熄灭、运行屏保。切回 Wi-Fi、拔掉模块或退出 App 释放声明。相比整机睡眠会增加耗电。

它不能阻止手动睡眠、合盖睡眠或低电量等系统强制睡眠。真正唤醒后，工具等待模块重新枚举，尝试恢复 4G 路由并清理失效代理连接；USB 等待窗口约两分钟。若模块硬件未恢复，仍需检查线材、供电和系统 USB 列表。

## 联网检测与站点选择

点击第一级菜单的“检测能否上网”即可测试两类网络：

- 普通联网：直接请求普通站点，验证响应和 HTTP 状态。
- VPN 联网：对所选 HTTPS 站点建立连接并进行证书验证的 TLS 握手。有现有 Clash TUN / 系统代理时使用其本地 mixed-port，否则测试当前直接路径。

“VPN 检测站点”也在第一级菜单。可勾选 Google、YouTube、ChatGPT、Claude、Grok、Gemini、TikTok、X、Instagram、Facebook、Wikipedia。只测试勾选项；全部取消时普通联网照常检测，VPN 状态显示“未选择检测站点”。更改勾选会清理过时结果。

正常站点不逐个占用菜单行；失败站点单独用红色显示。此测试不请求完整首页，所以不会把常见的网页反爬 403 当作网络禁止。TLS 正常并不保证视频、登录、API、地区限制或账号订阅正常。测试不创建或提供 VPN。

如果检测期间出口发生变化，结果标为网络已改变，应重新点击检测。可用“重新检测代理出口”刷新现有代理绑定；不会替你选择代理节点。

## 套餐流量

首次使用时，在菜单确认运营商，然后点击“首次短信同步剩余流量”。这会向运营商服务号码发送一条查询短信；界面等待回复并尝试解析通用流量。首次安装和状态轮询都不会自动发送短信。

| 运营商 | 默认查询 | 可选项 |
| --- | --- | --- |
| 电信 | 108 → 10001 | 自动识别或手动选择运营商 |
| 移动 | CXLL → 10086 | 自动识别或手动选择运营商 |
| 联通 | CXTCYL → 10010 | 2082、CXLL、1071、地区性 CXLLJ、CXYE、CXTC、CXTQ |

联通标准查询依据 [官方短信指令表](https://iservice.10010.com/elecService/message.html)。不同省份、卡种和企业/物联网套餐可能不返回数字，只给官方 App 链接。此时明确显示“短信未返回流量额度”，不会把查询链接或话费当作剩余 GB。可自行更换菜单内的只读查询指令后再点击同步；不能保证所有卡都支持短信额度查询。

成功取得短信额度后，以“短信基线 − 此后模块本地 RX + TX 增量”估算剩余，后续不自动发短信。需要对账时手动点击“短信同步剩余流量”。

本地累计不等同于运营商结算：App 未运行、模块接到 iPad / 其他电脑、其他共享成员、定向流量、结转规则、计费舍入等都会造成差异。跨月需要重新短信同步。计数器重置或换 USB 网卡时重建计数基线，避免将历史字节重复扣减。SIM 更换后按哈希建立独立记录并取消旧卡待处理的查询。

同时存在多个无法确定关系的额度时，宁可显示未识别，也不盲目相加。套餐共享信息可能显示提示。移动的解析器已测试，当前发行验证没有真实移动 SIM 实测。

## 通话、短信和权限

主界面的拨号、通话音频、通讯录与短信沿用增强版 v1.2.9。允许麦克风才能传递本机语音；通讯录权限用于显示联系人。不会在安装中自动拨号、发送普通短信、开启 ADB 或改写模块 USB 配置。

SIM 必须支持语音业务，数据卡不能因为安装软件就获得通话能力。USB 音频 / 模块通话组件的要求见 [增强版文档](https://github.com/rogerbush007-a11y/DJOneHub-mac-enhanced)。已有授权和模块组件不会被本次整合清除。

## 用于 iPad / iPhone

Mac 菜单仅控制 Mac，不能在 iPad 上运行。可在 DJOneHub 的模块设置里切到 iPhone/iPad USB 模式，按界面提示拔插使配置生效。

iPad 若 USB-C 直连没有“以太网”，可尝试带 PD 供电的 USB-C 扩展坞 + USB-A 数据口 + USB-A 转 USB-C 数据线。模块不要接扩展坞的 PD 充电口。在已解锁状态连接并批准配件，将“配置 IP”和 DNS 保持自动。

已在一台 iPad Pro M1 上验证过扩展坞连接取得 192.168.225.x 并上网；不是对所有 iPad、iOS、线材或 USB-C 直连的兼容承诺。模块接 iPad 时，本机 DJOneHub 不再拥有其 USB 控制接口，读取基本信息和信号可能不可用。

## 设置按钮颜色

可用操作显示绿色。检查通过保留绿色及 ✓，失败显示红色及 !；重启模块使用红色提醒。处理中和不可用按钮禁用并显示灰色，实体 SIM 的 eSIM Profile 下载不可用。更改网络策略或 USB 模式会清除原来的检查结果。

联通指令在菜单「查询运营商 → 联通查询指令」选择。1.0.2 增加 CXYE、CXTC、CXTQ；选择只保存，点击短信同步才发送。若回复只有话费金额而没有流量，不会建立或覆盖流量基线。
